# Anon CMS Theme List

This repository contains a list of themes for Anon CMS.

## JSON Format

The list of themes is stored in a JSON file.

```json
{
    "name": "theme name",
    "author": "you name",
    "screenshot": "image url or repositories path",
    // "screenshot": "screenshot.jpg", Repositories Path + screenshot
    // "screenshot": "https://i0.hdslb.com/bfs/archive/4fd3f7028454e6019fcc6f88606cab6e0bb2f306.jpg",
    "url": {
        "github": "GitHub url",
        "gitee": null
    }
}
```
